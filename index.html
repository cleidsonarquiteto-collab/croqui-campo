Sistema de coordenadas

O croqui usa um sistema próprio: origem (0;0) no ponto que você escolher, x para a direita, y para cima, em metros. Abaixo, onde essa origem cai no sistema maior (lote, prédio, levantamento). Na exportação, cada registro leva as duas coordenadas.
